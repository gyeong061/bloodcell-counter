- **WBC 종류 분류는 하지 않음** (2026-10-24): TXL-PBC의 PBC 500장은 5종류뿐이고 분엽호중구가 없으며 test가 종류당 8~12장 → README '검토했지만 하지 않은 것'에 근거 기록

## 추가 실험 후보 (시간이 남으면)

- 추론 입력 방식(640×480 그대로 vs 640×640 패딩)에 따른 RBC 개수 차이

- imgsz 640 vs 960: 작은 혈소판 recall이 오르는지
- 증강 하나씩 빼 보기 (상하 반전, HSV) → 어떤 증강이 효과였는지
- 실험 2도 시드 반복 (YOLO11n vs 11s 차이 −0.21이 유지되는지)
- 넓은 시야 도말에서 남은 RBC 과다 카운트(편향 +1.25) 원인 분석
- 출처별 성능 차이(Raabin-WBC가 낮음) 원인 분석: 색 정규화 증강 시도

## 포트폴리오에서 강조할 이야기

1. **문제 정의**: "탐지"가 아니라 "세기"가 서비스 가치 → 카운트 오차 지표를 직접 설계
2. **이전 프로젝트에서 배운 점 적용**: Test 세트 분리, 같은 epoch 비교, 분할 간 누수 점검
3. **데이터를 의심하기**: 라벨 오류·중복 시야를 찾아 기록
4. **끝까지 만들기**: 학습 → 평가 → API → 웹 → PDF 리포트 → 배포
